# Scriptcase PDF Mapper

Mapper PDF per Scriptcase: posizionamento campi su template PDF tramite interfaccia drag & drop (interact.js, PDF.js).

## Requisiti

- PHP (per ambiente Scriptcase)
- Browser moderno (PDF.js, interact.js via CDN)

## Utilizzo

Inserire il file in un’applicazione Blank di Scriptcase e configurare `[glo_template_id]` per il template da modificare. I campi trascinabili sono definiti in modo statico nell’interfaccia.
